# pyvvo/.github

This repository holds the default community files of the pyvvo organization on GitHub. A pyvvo repository that has no
file of the same name uses the one here:

- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md): the code of conduct.
- [`SECURITY.md`](SECURITY.md): how to report a vulnerability.
- [`CONTRIBUTING.md`](CONTRIBUTING.md): how to contribute. funcd has its own guide.

It also holds the [Corporate Contributor License Agreement](CLA-corporate.md). A contributor accepts the
[individual agreement](https://gist.github.com/green-0-rabbit/832cfeea256955cacecc9c1b2f108a82) through the CLA assistant on a first pull request.
