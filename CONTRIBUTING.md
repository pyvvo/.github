# Contributing to pyvvo projects

Thank you for your interest in a pyvvo project.

- Open an issue first, and describe the bug or the change that you want. A maintainer answers there.
- Before we can merge your first pull request, you sign the pyvvo Contributor License Agreement (CLA). The CLA
  assistant comments on your pull request with a link. One signature covers every pyvvo repository. If you contribute
  on behalf of your employer, your employer signs the [Corporate CLA](CLA-corporate.md) first.
- A pull request title follows [Conventional Commits](https://www.conventionalcommits.org/), for example `fix: …` or
  `feat: …`. The title becomes the commit message, and the changelog is written from it.
- A bug fix comes with a test that fails without the fix.
- Report a vulnerability privately, as the [security policy](SECURITY.md) describes.
- Everyone follows the [code of conduct](CODE_OF_CONDUCT.md).

The funcd repository has a longer guide: [funcd/CONTRIBUTING.md](https://github.com/pyvvo/funcd/blob/main/CONTRIBUTING.md).
