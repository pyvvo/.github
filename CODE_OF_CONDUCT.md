# Code of conduct

Everyone who takes part in a pyvvo project, in issues, pull requests, discussions and every other project space,
follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

To report unacceptable behavior, write to **community@pyvvo.io**. The maintainers read every report, keep the
identity of the reporter private, and respond as the enforcement guidelines of the Contributor Covenant describe.
